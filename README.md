## Potato Clicker

A simple incremental web game where you collect potatoes by clicking and purchasing upgrades and buildings to increase your potatoes per second (PPS). 

## Features

- Click the Big Potato to collect potatoes.
- Purchase buildings (Farm, Food truck, Chips factory, Potato cloner) to increase PPS.
- Buy upgrades (Harvester, Poutine maker, Instant fryer, Advanced DNA) to double the production of each building type.
- Random bonus potatoes appear for temporary PPS boosts.
- Achievements for reaching powers of ten in potatoes.

## Folder Structure

```
.
├── Buttons.js         # Button and upgrade logic
├── Counter.js         # Counter and game state logic
├── Game.html          # Main HTML file
├── styles.css         # Game styling
└── Figs/              # Image assets for potatoes, buildings, and upgrades
```

## How to Run

1. Download or clone this repository.
2. Open Game.html in your web browser.
3. Play the game!

## File Descriptions

- **Game.html**: Main HTML file. Loads the game UI and scripts.
- **Buttons.js**: Contains all button classes (clicking, building, upgrade, bonus).
- **Counter.js**: Manages potato count, PPS, achievements, and bonus logic.
- **styles.css**: Styles for layout, buttons, messages, and images.
- **Figs/**: Contains all image assets used in the game.
